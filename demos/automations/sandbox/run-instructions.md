# Stock-check run instructions

Work only inside the selected practice sandbox.
Run `python -m unittest`. If tests fail, report the failure and stop.
Otherwise run `python check_stock.py`.
Report the test result, low-stock count, item names, and remaining quantities
in this session. Do not order supplies or contact anyone.
Do not change source files, inventory, tests, or these instructions.
Do not install packages, access the network, or commit changes.
