# Droid Coach website and enablement materials

Materials for learning Factory Droid.

| Folder | What it is |
| --- | --- |
| [`droid-coach/`](droid-coach/README.md) | The `/droid-coach` skill and a public learning website with guided lessons and an optional live AI coach. Start here. |
| [`demos/`](demos/) | Five-minute demos generated by the coach (Spec Mode and Automations), each with a small practice sandbox. |
| [`factory-workshop-prep/`](factory-workshop-prep/README.md) | A `/prepare-workshop` skill that turns a discovery brief into a workshop plan. All customers in it are fictional. |

To run the website locally, follow [droid-coach/README.md](droid-coach/README.md#website).
