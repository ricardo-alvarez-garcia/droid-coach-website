# Demo template

Use this structure for every `demo.md`. Replace everything in angle brackets. Keep the whole file to 600 words or fewer.

```markdown
# 5-minute demo: <Feature name>

Surface: Factory App · Level: <level> · Docs fetched: <YYYY-MM-DD>

## What you'll learn
<One sentence: the problem this feature solves and what you will do with it.>

## Setup (0:00, 30 seconds)
1. Copy the `sandbox/` folder next to this file to a scratch location, for example your Desktop.
2. In the Factory App, start a new session with that folder as the working directory.
<Any one-off setup the feature needs, such as choosing a mode. Nothing else.>

## Steps

### Step 1 (0:30): <short title>
**Type this:**
```text
<exact prompt or action>
```
**You should see:** <observable result>
**What just happened:** <one or two sentences tying the result to the feature, with a docs link>

### Step 2 (<m:ss>): <short title>
<same structure>

<Three to five steps in total. The last one finishes by 5:00.>

## Recap: you can now
- <observable action 1>
- <observable action 2>
- <observable action 3>

## Next
Try `/droid-coach demo <next feature>`: <one sentence on why it is the natural next step>.

## Sources
- [<Page title>](<url>), fetched <YYYY-MM-DD>
```

Rules:
- Time stamps are when each step starts. Budget about 30 seconds for setup and 45 to 75 seconds per step.
- "Type this" is text the learner can paste unchanged. If the action is a click or a mode switch, describe it using the labels from the docs.
- Every "What just happened" links one fetched docs page.
